# 체크리스트 — 한 칸씩

ROADMAP이 이 파일을 가리킬 때만 연다. **한 줄만** 하고 통과를 확인한 뒤 다음 칸. 이 파일 전체를 한 번에 구현하지 않는다.

**시작 규칙:** 코드를 고치지 말고, 지금 열려 있는 칸 번호와 플러그인 상태를 짧게 말한 뒤 시작 여부를 묻는다.

모델은 `.env`가 아니다. **패널 드롭다운.** 키만 `sidecar/.env`의 `CURSOR_API_KEY`.

Cursor 앱 채팅 / `mcp.json`으로 에디터를 조종하지 않는다. MCP는 사이드카 에이전트가 언리얼을 치기 위한 손이다.

표기: `[x]` 코드에 이미 있음(에디터에서 사용자 확인 전). `[ ]` 아직.

## J. 배포 (마지막)

코딩하면서 설치 경로가 바뀔 수 있다. **이 장을 열 때** 플러그인·사이드카·키 넣는 법이 실제로 어떤지 적고, 그걸 기준으로 패키징한다. 지금 시점의 `venv` / 폴더 복사를 여기 칸에 미리 못 박지 않는다.

## 하지 말 것

Cursor 앱 `mcp.json` 필수 경로. Cursor를 에디터에 이식. 키를 `.env` 밖으로. 모델을 `.env`에만 고정. 원격 MCP. 도구 수십 개. Landscape/Niagara/Blueprint 그래프. Fab. `UnrealEditor-Cmd`로 패널 대체. JSON 파싱으로 `spawn_cube` 이중 구현. 모든 스레드 히스토리를 매 요청에 실음. **배포 전에 옛 설치법을 문서에 고정하기.**
