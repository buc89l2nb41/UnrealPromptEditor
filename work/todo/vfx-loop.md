# 체크리스트 — 레퍼런스 VFX 루프

Editor Prompt 제품은 그대로다. 패널 → MCP → 뷰포트.

VFX 요청의 본선은 **손 추가가 아니라** 레퍼런스 이미지를 보고 맞추는 에이전트 루프다. 규칙은 `sidecar/vfx/AGENTS.md`.

표기: `[x]` 코드에 있음. `[ ]` 아직. **한 칸씩.**

**시작 규칙:** 코드를 고치지 말고 칸 번호만 말한 뒤 시작 여부를 묻는다. 이 장을 연 뒤의 첫 칸(V1)은 계획 전환과 같이 착수해도 된다.

7Q는 사용자 에디터 패스. 이 파일에서 구현하지 않는다. Grid2D 컴파일·GPU 셰이더 대기는 **본선이 아니다.** 손 목록에서 지우지 않고, 레퍼런스가 격자/유체일 때만 쓴다.
