# work — 에디터 프롬프트 Agent용

채팅에서 **에디터 프롬프트 Agent**로 부르면 여기다. 진입은 [`../README.md`](../README.md).

이 폴더만 다룬다. 다른 게임 프로젝트의 `work/`·소스·맵을 읽거나 고치지 않는다.

**시작 규칙:** 코드를 고치지 말고 ROADMAP + 가리키는 작업 한 장 + (있으면) 플러그인 상태를 짧게 말한 뒤, **시작할지 묻는다.** “해” 전에는 구현·에디터 조작·API 키 파일 없음.

**읽는 순서:** [`ROADMAP.md`](ROADMAP.md) → `todo/` **한 장**. `todo/`·`done/`을 전부 읽지 않는다.

새 할 일은 [`todo/`](todo/)에 둔다. 통과하면 [`done/`](done/)으로 옮기고 이 표와 ROADMAP을 고친다.

| 경로 | 역할 |

| [`todo/`](todo/) | 할 일 한 장 |
